verb×ノードの行列テストは、書いた最初の実行で横断制約 (phase と gate の整合) を炙り出した。

# 行列テストは初回実行で元を取った

全 verb × 全ライフサイクルノードを機械的に回す T-MX-1 は、最初の実行で
「`in_progress/research+plan` のノードでは gate が light でなければ phase-pass の辺が
存在しない」という横断制約を検出した (既定 gate full のフィクスチャが conflict になった)。
これは実装のバグではなく、フィクスチャ側がノードと gate の整合という暗黙の制約を
知らなかったことの検出で、修正としてフィクスチャをノード依存 (関数形 overrides) にした。

教訓: 行列テストの維持コスト (verb ごとの補助前提フィクスチャ) は無駄な出費ではなく、
「その verb が発火するために何が揃っている必要があるか」の実行可能な文書になる。
網羅形のテストは書いた瞬間から、単発テストでは踏まない組み合わせを踏む。
